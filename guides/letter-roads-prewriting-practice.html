How to Use Letter Roads for Prewriting Practice

Letter roads turn the path of a letter into a route children can follow with a finger, a toy car, or another small object before they are asked to write.

Author: Sensory SpOT Studio

Intended audience: Preschool and early elementary educators, occupational therapists, and families

Supplies

  • Uppercase and lowercase letter-road pages
  • A small toy car or another easy-to-move object
  • Optional dry-erase sleeve and marker
  • Paper and a writing tool for the final transition

Begin with letter recognition

Choose one letter and name it before beginning the path. Compare the uppercase and lowercase versions when both are appropriate for the learner. Notice one or two visible features—straight lines, curves, tall parts, or short parts—without turning the activity into a long verbal lesson.

If the child is still learning to identify the letter, place it beside one contrasting letter and ask them to find the matching road.

Find the starting point

Point out the starting marker and the first directional arrow. Use simple language such as “Start here, then drive down.” Follow the printed route instead of beginning wherever the car happens to land. Consistent starting points help connect the playful path with the movement sequence used later in writing.

Drive the path with a toy car

Move slowly enough to stay on the road. Pause at turns and changes in direction. The goal is not speed; it is noticing and following the sequence of the letter. An adult can model the first trip, then let the child drive independently or guide the car together.

For letters with more than one stroke, return to the next starting point rather than drawing an extra connecting route that is not part of the letter.

Repeat the path with a finger

After the toy car, trace the same route with an index finger. This removes the extra object while keeping the large, visible pathway. Say the direction in a short phrase if that helps: “Down, back to the top, across.” Keep the language consistent across repetitions.

Connect the path to visual-motor practice

Ask the child to watch the path while moving along it, then try the route without the car. The eyes guide the hand through changes in direction, stops, curves, and crossings. A dry-erase marker can be a useful bridge because it leaves a visible trace that can be checked and tried again.

Transition toward handwriting

  1. Drive the full-size letter road.
  2. Trace it with a finger.
  3. Trace it with a marker in a sleeve.
  4. Copy a large version onto paper.
  5. Try a smaller version only when the larger movement feels manageable.

The transition does not need to happen in one sitting. A child may benefit from returning to the large path on another day before trying paper again.

Adapt the activity

Make it more accessible

  • Work with one letter at a time.
  • Use the uppercase version first when its form is visually simpler.
  • Stabilize the page on a table or vertical surface.
  • Use a larger object if grasping a small car distracts from the route.
  • Offer hand-under-hand support only when appropriate and welcomed.

Add variety

  • Use a finger puppet, craft pom-pom, or eraser as the traveler.
  • Build the same letter with craft sticks or a flexible material after tracing.
  • Match a picture whose name begins with the practiced letter.
  • Alternate between uppercase and lowercase forms.
